1. FILE INFORMATION
- Show the uploaded file name.

- Handle long filenames gracefully with truncation.

2. REAL-TIME UPLOAD PROGRESS
Display:
- Percentage: 0% → 100%
- A horizontal progress bar
- Upload speed, e.g. "74 KB/s"
- Estimated remaining time, e.g. "28 seconds"
- Current status

Example:

Uploading 1 of 1 file
Scalenut-signed (1).pdf (3.54 MB)

Upload speed: 74 KB/s
Estimated time remaining: 28 seconds

[████████████████░░░░░░░░] 43%

When completed:

100%
Upload complete

3. REAL PROGRESS — NOT FAKE ANIMATION
Do NOT use a fake timer or artificially increase the percentage.

Use the actual upload progress provided by the browser/network request.

For XMLHttpRequest, use:
xhr.upload.onprogress

For fetch/API requests where native upload progress is unavailable, implement an appropriate XMLHttpRequest-based upload mechanism or another technically reliable method.

The percentage must reflect the actual bytes uploaded:

percentage = (loaded / total) * 100

Calculate upload speed from actual bytes transferred over time.

Calculate estimated remaining time from:
remainingBytes / currentUploadSpeed

4. UPLOAD STATES

Implement these states:

IDLE
- Normal upload/dropzone UI.

SELECTED
- File selected but upload has not started.

UPLOADING
- Show progress percentage.
- Show progress bar.
- Show upload speed.
- Show estimated remaining time.
- Show file name and size.

PROCESSING
After upload reaches 100%, do NOT immediately tell the user the entire operation is complete.

Change the status to:

"Upload complete"
"Processing your file..."

Show an indeterminate processing animation while the backend processes the PDF.

COMPLETED
When processing finishes:

"Completed"
Show the existing download/result UI.

ERROR
If upload or processing fails:

"Upload failed"
or
"Processing failed"

Show a clear error message and a "Try again" button.

CANCELLED
If cancellation is supported:
"Upload cancelled"

5. CANCEL UPLOAD

- Abort the active upload request.
- Stop the progress calculation.
- Reset the UI safely.
- Allow the user to upload the file again.
