==================================================

This is one of the most important parts of the project.

Create a robust coordinate abstraction.

The system must correctly convert between:

- PDF coordinates
- Page coordinates
- Viewer coordinates
- Screen coordinates
- Zoomed coordinates
- Device-pixel coordinates
- Export coordinates

Handle:

- Zoom
- Scroll position
- Responsive resizing
- Device pixel ratio
- Page rotation
- Different page dimensions
- Landscape orientation

Do not use fragile hard-coded pixel offsets.

Do not assume every PDF page has the same dimensions.

Create reusable coordinate transformation utilities with strong TypeScript types and automated tests.
